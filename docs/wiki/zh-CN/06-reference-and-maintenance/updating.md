# 更新 Omera

Omera 可以检查新版本并下载经过验证的安装包。安装更新需要你操作，具体步骤取决于操作系统。

## 检查更新

选择**帮助 > 检查更新**。可在**首选项 > 常规**中开启或关闭启动时检查。安装前请阅读版本说明。

## 下载与安装

1. Windows 点击**立即更新**即可自动下载并安装，开始前可选择静默安装。macOS/Linux 请先选择**下载新版本**。
2. Omera 会验证下载的安装包，并在启动安装程序前再次验签。验证失败会停止安装；启动安装程序失败后，可使用已下载的安装包重试。
3. Windows 会更新现有应用，并在成功后重新打开 Omera，无需单独卸载。macOS 请点击**立即安装并重启**打开已验证的 DMG，完成安装后重新打开 Omera。Linux 的安装操作会启动 AppImage；DEB/RPM 包需通过包管理器安装。macOS/Linux 不保证自动重启应用。

若缺少更新信任配置、签名缺失或验证失败，可选择**在浏览器中下载**或 **GitHub Releases** 打开[官方发布页面](https://github.com/BerryUIKI/Omera/releases)。选择适合操作系统和架构的安装包，并按其说明手动安装。请勿关闭签名验证或使用不可信的镜像。未配置更新信任的旧版本需要先手动升级到可信版本。

## 保留图库

程序文件与用户数据分开存储。升级前请保留最新的数据库备份，以及原始媒体和设置。启动时的数据库结构迁移采用追加式迁移；1.0 之前的版本继续支持旧版数据发现和导入。升级时不要删除应用数据或旧版源数据。
