# 云端快照备份与增量同步

Omera 内置了专用的云端快照备份与差异增量同步引擎（`src-tauri/src/cloud_backup.rs` 与 `src-tauri/src/cloud_sync.rs`），无需依赖任何第三方繁琐的备份软件，即可实现数据库的一致性快照备份以及远程媒体资产的增量镜像。

---

## 1. 支持的云存储服务商与协议

在**首选项设置 > 云端备份与快照**中配置你的远端存储终结点：

| 服务商类型 | 支持协议与服务 | 技术实现要点 |
| :--- | :--- | :--- |
| **S3 兼容对象存储** | AWS S3、Cloudflare R2、MinIO、Backblaze B2、Wasabi | 纯 Rust 原生实现的 AWS Signature Version 4 (SigV4) 鉴权协议，HMAC-SHA256 签名传输。 |
| **WebDAV 私有云** | Nextcloud、ownCloud、群晖 (Synology DiskStation)、威联通 (QNAP NAS) | 基于 HTTPS 加密通道的工业标准 HTTP Basic Authentication。 |
| **本地目录 / 网络存储** | 本地从盘、高速外接移动 SSD、局域网 SMB / NFS 共享文件夹 | 纯本地/局域网文件系统极速零开销 I/O，无额外协议封装损耗。 |

---

## 2. 数据库快照备份

快照包含 `omera.db` 和 `manifest.json`，保存图库记录、标签与评分，不包含媒体文件、设置或凭据。在**设置 > 云端备份**中配置目标，然后选择**立即创建快照**进行手动备份。归档名称唯一，本地发布采用原子操作。现有备份不会自动删除。

### 自动备份

默认**关闭**，间隔为**七天**。启用后选择 **1–365 天**并**保存设置**。取消或保存失败会保留原计划。Omera 运行时每 30 秒检查，首次备份将在下一次检查开始；后续间隔从成功备份完成时计算。退出 Omera 会停止调度；关闭自动备份会停止后续任务，正在进行的备份可完成。

**已保存的计划**独立于待保存编辑显示运行状态、上次成功与尝试、下次时间、归档和错误。失败或中断后等待**一小时**重试，重启后也遵循此规则。更换目标会建立新计划，仅轮换凭据不改变时间。损坏的计划文件会保留并暂停调度，修复后需重启 Omera。

### 恢复

恢复会验证快照，并暂存到下次应用启动时启用。请退出并重新启动 Omera，单独刷新窗口不足以启用恢复。启动时会先将当前数据库保存为独立的 `omera.pre-restore-<UUID>.db` 恢复点，再事务性启用快照。快照不能恢复丢失的媒体或凭据。

## 3. 增量媒体镜像与差异同步 (`cloud_sync.rs`)

如果说快照负责守护数据库的元数据骨骼，那么**差异同步 (Delta Sync)** 则是为你数以万计的原始图片与视频原图提供从本地到远端的单向增量镜像上传保障。

### 同步引擎核心能力（已实现）：
- **两档差异比对策略 (Change Detection)**：
  - *快速指纹*：比对本地文件大小与远端文件元数据（HEAD 查询，速度最快，适合常规网络环境）。
  - *严格校验*：本地计算 SHA-256 哈希比对远端（S3 为自定义哈希头），保证文件二进制级别的完全一致性。
- **令牌桶带宽限速 (Token-Bucket Rate Limiter)**：支持在设置中设定上传速率上限（KB/s），确保后台云同步不会挤占工作室的正常工作带宽。
- **并发工作线程调节**：可按硬件与网络条件配置 1 到 16 个并发上传传输线程（默认 4 个）。
- **演练模式 (Dry-Run)**：在真正发起上传前，仅比对差异并输出待上传与待跳过的文件清单报告，不产生实际写入。
- **实时进度推送**：向前端高频广播包含已传字节数、实时传输速度、剩余预估时间（ETA）与当前文件名的进度事件，并支持原子协作式取消。

### 当前能力限制与规划功能：
- **仅支持单向上传**：当前同步路径仅负责将本地已索引的媒体文件镜像上传至远端存储，暂不提供从远端拉取/下载媒体至本地的对齐能力。
- **无远端删除同步**：本地删除文件不会级联删除远端文件，远端数据得以完整保留。
- **未启用 ETag 差异核验**：变动侦测基于文件大小与 SHA-256 头信息，服务商 HTTP ETag 不参与缓存对齐。
- **规划中双向同步**：具备冲突裁决、远端变动侦测与差异拉取的全功能双向同步属于后续版本规划。
