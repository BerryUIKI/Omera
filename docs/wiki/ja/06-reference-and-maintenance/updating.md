# Omera の更新

Omera は新しいリリースを確認し、検証済みのインストーラーをダウンロードできます。インストールには操作が必要で、手順は OS によって異なります。

## 更新の確認

**ヘルプ > アップデートを確認**を選択します。起動時の確認は**環境設定 > 一般**で切り替えられます。インストール前にリリースノートを確認してください。

## ダウンロードとインストール

1. 自動ダウンロードを選ぶと、公式 GitHub リリースからパッケージを取得します。
2. Omera はインストールを提示する前と、インストーラーを起動する前に署名を検証します。エラーが出た場合、インストールは許可されません。
3. Windows の EXE は選択したサイレントインストール設定を使用できます。macOS では検証済み DMG が開くので、インストールを完了して Omera を開き直します。Linux では AppImage が起動します。DEB/RPM はパッケージマネージャーでインストールしてください。すべての OS で自動再起動するとは限りません。

更新の信頼設定がない場合や、署名が欠落している場合、検証に失敗した場合は、**ブラウザでダウンロード**または **GitHub Releases** から[公式リリースページ](https://github.com/BerryUIKI/Omera/releases)を開きます。OS とアーキテクチャに合うパッケージを選び、その手順で手動インストールしてください。検証を無効にしたり、信頼できないミラーを使ったりしないでください。更新の信頼設定がない旧バージョンでは、最初に信頼できるビルドへ手動更新が必要です。

## ライブラリの保持

アプリ本体とユーザーデータは別々に保存されます。更新前に最新のデータベースバックアップを作り、元のメディアと設定を保持してください。起動時のスキーマ移行は追加方式です。1.0 より前のリリースは旧データの検出とインポートを引き続きサポートします。更新のためにアプリデータや旧データを削除しないでください。
