# 更新 Omera

Omera 可以檢查新版本並下載經過驗證的安裝套件。安裝更新需要您操作，步驟取決於作業系統。

## 檢查更新

選擇**說明 > 檢查更新**。可在**偏好設定 > 一般**中開啟或關閉啟動時檢查。安裝前請閱讀版本說明。

## 下載與安裝

1. Windows 點擊**立即更新**即可自動下載並安裝，開始前可選擇靜默安裝。macOS/Linux 請先選擇**下載新版本**。
2. Omera 會驗證下載的安裝套件，並在啟動安裝程式前再次驗證簽章。驗證失敗會停止安裝；啟動安裝程式失敗後，可使用已下載的套件重試。
3. Windows 會更新現有應用程式，並在成功後重新開啟 Omera，無需另外解除安裝。macOS 請點擊**立即安裝並重啟**開啟已驗證的 DMG，完成安裝後重新開啟 Omera。Linux 的安裝操作會啟動 AppImage；DEB/RPM 套件需透過套件管理員安裝。macOS/Linux 不保證自動重新啟動應用程式。

若缺少更新信任設定、簽章缺失或驗證失敗，可選擇**在瀏覽器中下載**或 **GitHub Releases** 開啟[官方發布頁面](https://github.com/BerryUIKI/Omera/releases)。選擇適合作業系統和架構的套件，並依說明手動安裝。請勿關閉簽章驗證或使用不可信的鏡像。未設定更新信任的舊版本需要先手動升級到可信版本。

## 保留圖庫

程式檔案與使用者資料分開儲存。升級前請保留最新的資料庫備份，以及原始媒體和設定。啟動時的資料庫結構遷移採用追加式遷移；1.0 之前的版本繼續支援舊版資料探索和匯入。升級時不要刪除應用程式資料或舊版來源資料。
